# Intervjuu-protokoll — vananenud

> **See fail ei ole enam kasutusel.** Ta sisaldas paralleelset intervjuu-prompti, mis kirjeldas süsteemi vana kuju ega vasta praegusele lepingule. Kahe eri kohas hoitud intervjuuloogika oli täpselt see, mis lasi neil vaikselt lahku triivida.

Intervjuu elab nüüd ühes kohas, ühest allikast.

## Kuhu minna

| Sa tahad | Mine siia |
|---|---|
| intervjuud teha, Skill installitud | ütle Claude'ile `töötoa intervjuu` |
| intervjuud teha ilma installimata | juurkausta `quick-interview.md` |
| aru saada, mida kiire režiim lubab | `skills/konteksti-looja/references/quick-mode.md` |
| aru saada süvarežiimi moodulitest | `skills/konteksti-looja/references/deep-mode.md` |
| teada, kuidas väiteid märgistatakse | `skills/konteksti-looja/references/claims-and-evidence.md` |
| teada, mis kujuga failid välja tulevad | `skills/konteksti-looja/references/output-contract.md` |
| täita üht faili korraga | ava šabloon `portfolio/templates/` kaustast |

Süsteemi kuju ja failide rollid: `portfolio/context-map.md`.

Alustamine: repo juurest `quick-start.md`.
